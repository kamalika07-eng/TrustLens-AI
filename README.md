# TrustLens-AI
AI-powered payment message security analyzer
TrustLens-AI 🛡️

An AI-powered phishing message and suspicious URL detection system.

About the Project

TrustLens-AI is a cybersecurity application designed to identify suspicious payment messages and potentially malicious URLs. It provides risk scores and explanations to help users understand potential online threats.

Features

- Suspicious message detection
- Phishing URL analysis
- Risk score generation
- Explainable detection results
- User-friendly Streamlit dashboard

Technology Stack

- Python
- Streamlit
- Machine Learning / NLP (as implemented in the project)
- HTML and CSS (if used)
